# 项目数据集

本目录用于存放自己的方法与 CCDC、COLD、SCCD 对比实验所需的数据。

## 目录用途

- `raw/`：原始影像或像元时间序列，保留原始文件以便追溯。
- `processed/`：完成质量筛选、时间排序及格式转换的数据，供各方法读取。
- `reference/`：参考标注或验证数据，例如变化位置、变化时间、变化类型及未变化样本。

建议按研究区或数据集名称建立子目录，例如 `raw/study_area_01/`。现有数据可先按原有格式放入，不必提前转换。

## 数据说明

放入数据后，请在此补充：

- 数据来源、传感器、研究区域和时间范围。
- 文件格式、坐标系与空间分辨率（如适用）。
- 波段顺序、数值缩放、缺失值、质量标记及日期编码。
- 参考标注来源、字段含义及训练、调参与测试样本划分（如适用）。

## 对比实验约定

各方法尽量使用相同的观测数据、研究范围与评价样本；必要的输入转换和预处理差异应记录清楚。根据研究任务确定评价指标和变化时间的容差，再进行对比。

运行结果应另行保存，并记录方法版本、参数与运行时间，避免覆盖原始数据。
