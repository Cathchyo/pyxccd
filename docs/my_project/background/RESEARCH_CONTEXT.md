## 导师希望推进的主线

利用历史时间序列预测正常情况下的观测值，再将预测与实际观测比较，根据偏离情况判断是否发生扰动。

这里的核心训练任务是时间序列预测或相关的动态建模；扰动判定建立在预测与观测的差异上。残差如何标准化、需要连续多少次异常、何时重建正常模型等规则尚未确定。

## 当前计划与探索路线

### 先建立序列分类基线

用户计划先用“时间序列 → 是否发生扰动”的标签开展监督训练，考察深度学习直接分类的效果，再回到预测驱动的检测主线。该步骤是对照实验，不表示导师要求已改为分类任务。

当前仓库包含 HLS 六波段序列的 Transformer/SITS-BERT 分类复现、51RTQ 数据和训练结果。这些是已有实验基础，不表示最终研究的数据范围、模型或任务形式已经确定。

### 探索自监督预测

使用大量时间序列，通过自监督方式学习预测。具体预测目标、输入窗口、模型结构及训练样本的稳定性要求尚未确定。

用户关心预训练之后如何持续吸收新观测。不能据此断言自监督预测模型无法更新；固定模型推理、输入上下文更新、隐状态更新和模型权重更新需要分别讨论。

### 探索学习曲线参数的更新规律

用户提出：借鉴 CCDC 对稳定历史序列拟合正常变化曲线、发生扰动后重新拟合的思路，研究能否让深度学习学习曲线系数的变化或更新规律，而不只直接预测观测值。

已确认同时研究稳定时期的参数更新和扰动后的参数转换，其中**扰动前后两套曲线系数的转换是模型学习的重点**。稳定时期应如何更新，用户计划先查阅 CCDC、SCCD 的具体机制，再确定方案。

### 已确认的训练样本设计：历史曲线与六次观测

模型输入包括一段正常历史曲线，以及后续窗口内的六次观测；模型输出一组更新后的曲线系数。“六次观测”是时间窗口长度，不是六个光谱波段。历史曲线具体输入为系数、曲线采样值还是原始历史序列，尚未确定。

以下窗口按从旧到新的顺序表示，`N` 表示正常观测，`D` 表示进入扰动后阶段的观测；该记号只用于说明训练设计，不表示应用时已知这些标签。

| 训练情况 | 窗口示例 | 目标系数 |
| --- | --- | --- |
| 六次观测均已进入扰动后阶段 | `D D D D D D` | 更新为扰动后的曲线系数 |
| 六次观测均正常 | `N N N N N N` | 保留原系数或小幅调整；具体规则待定 |
| 扰动刚进入窗口，正常与扰动后观测混合 | `N N N N D D`、`N D D D D D` | 仍对应扰动前的曲线系数，不提前切换到扰动后系数 |

用户明确：只有扰动后的观测已经到达窗口最前端，即整个六次观测窗口均处于扰动后阶段时，才切换到扰动后的参数。当前描述针对单次正常到扰动后的转换；多次扰动、异常噪声和恢复过程的处理尚未定义。

训练阶段可以获取扰动后的目标系数，用于监督学习。目标系数的拟合方法、拟合时间范围和质量控制仍需确定。这里学习的是曲线参数更新；不表示实际应用时需要对神经网络权重重新训练。

### 已确认的实际应用流程

1. 使用传统方法拟合初始历史曲线。用户提及 COLD/CCDC，具体初始化算法仍需确认。
2. 用当前曲线计算预测值。
3. 收集六次已到达的观测，将这些观测和当前曲线输入训练好的更新模型，得到新系数。
4. 用新系数计算下一个观测时刻的预测值，再与该时刻实际到达的观测比较，依据偏离检测扰动。
5. 持续接收观测并更新。窗口是否每到一次观测就滑动一步，以及系数如何逐步传递，尚待明确。

应用时不能把“六次观测全是扰动”当作已知条件直接交给模型；三类窗口对应训练样本及其目标设计。是否设置额外的扰动分类输出尚未确定。

## 关键动机：兼顾长期与短期信息

- 长期历史提供季节性、年周期等正常变化规律。
- 近期观测提供森林当前状态的信息，用户希望模型能及时吸收这些信息。
- 需要探索如何同时保留长期规律并响应近期变化；近期观测的有效性还取决于观测质量等条件，不能一律认为越近越可靠。

## 尚待确认的问题

1. 稳定时期参考 CCDC/SCCD 的哪一种更新机制？正常窗口与混合窗口的扰动前目标系数如何具体生成？
2. 历史曲线如何表示？模型是否还需要观测日期、时间间隔、质量标记或残差等输入？
3. 曲线函数的形式、各波段系数组织方式，以及训练目标系数的拟合方法与时间范围是什么？
4. 最终评价侧重回溯检测还是近实时检测？若面向近实时，预测和判定只能使用当时已到达的数据。训练目标可以离线拟合，但应按像元/事件及时间合理划分，避免未来数据进入应用输入或测试信息进入训练。
5. 六次观测窗口如何滑动？扰动报警如何累计，何时记录事件并切换曲线？切换为扰动后曲线后残差可能减小，因此事件记录不能只依赖切换后的单次残差；具体机制尚未定。
6. 如何应对不规则观测间隔、云污染、渐变胁迫、连续多次扰动及恢复？六次观测对确认延迟的影响需要评价，不能直接等同于六天。
7. 数据来源与范围、独立验证标签、对比方法、评价指标、毕业进度及计算资源仍需继续交流。
